# 🪔 Happy Diwali Python Project

A simple and interactive command-line Python script celebrating Diwali! It greets users by name and lets them choose different festive activities.

## ✨ Features
- Personalized user greeting.
- Interactive choice menu powered by Python's `match-case` statement.
- Festive messages for lighting diyas, bursting crackers, eating sweets, and home decoration.

## 🚀 How to Run
1. Make sure you have Python installed on your computer.
2. Clone this repository or download the `project1.py` file.
3. Open your terminal or command prompt in the project folder and run:
   ```bash
   python project1.py
